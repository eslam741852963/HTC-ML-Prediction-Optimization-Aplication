# HTC-ML-Prediction-Optimization-Application

## Note for Reviewers

**All codes in this repository were executed on the Kaggle platform.** 

The datasets used in this study are available in the **Supplementary Material**:
- **Supplementary Excel File 1:** The original compiled dataset (271 samples).
- **Supplementary Excel File 2:** The generated optimal data (813 points) used for training the inverse model.

If you want to run any of these codes locally, please replace the Kaggle paths (e.g., `/kaggle/input/...`) with the local paths to these files.
